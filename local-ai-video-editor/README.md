# Local AI Video Editor Skill v2

A development skill for a privacy-preserving AI-assisted video editing workflow with Adobe Premiere Pro 26.x.

**Purpose:** Help design and implement a local Python orchestrator, Adobe UXP interface, offline AI workers, and a mandatory human approval gate.

**Status:** Design/development instructions, not an already-working Premiere plugin or complete video-editing application.

**Hardware baseline:** Dell Precision 7960, Xeon w7-3445, 64 GB RAM, RTX 2000 Ada, 8 TB HDD. Hardware was accepted by the owner and does not need a repeated audit.

**Getting started:** Read `SKILL.md`, then implement milestones M0 and M1 with dummy media and deterministic test jobs. Use `references/` and `templates/` for system constraints.

**Privacy:** No uploading production media, transcripts, projects, or confidential derived information to external AI platforms.
